* Goal and scope

The frozen ten-v28 connected-ten census has 1043 unresolved original graphs: 430 pared-nine-core dependents (being investigated separately by Astra) and 613 stiff ten-vertex originals. The latter contain 610 originals in 514 certified exact P3-isomorphism classes and three historically P3-unreconstructed originals. Three oversized third-iterate classes (four originals) already received long-running native surveys. We study the remaining *511 exact P3 classes covering 606 stiff original ten-vertex graphs*.

This pilot is complementary to the exact general-coaffine-endomorphism survey in the sibling research directory. That survey found 420 positive coaffine maps on the same 511 classes, but most stable-image retractions were four-vertex squares and did not prove divergence. Its complete independently replayed positives already prove original McKay 10481909, 10586728, 11438191, and 11578321 divergent. Since the general solver can return a nonexpansive first image, it need not reveal an octahedral retraction even if one exists.

* Exact positive theorem

Let \(O_d=\overline{dK_2}\), where \(d\ge3\). Every maximal clique chooses one vertex from each antipodal pair; two such maximal cliques are disjoint if and only if their choices are complementary. Therefore \(K(O_d)\cong O_{2^{d-1}}\), and \(O_d\) is \(K\)-divergent.

If a completely pared third iterate \(X=P_3(G)\) admits an ordinary retraction \(r:X\to O_d\) onto an induced \(O_d\), then \(X\), and hence the original \(G\), is \(K\)-divergent by Neumann-Lara's retraction theorem and domination paring. An exact isomorphism \(P_3(G)\cong P_3(H)\) transfers that positive conclusion to the entire certified class.

The native search uses *only* the official \(pycliques.find_octahedral_retraction_coaffine\) public algorithm and its pre-existing native C++ backend, pinned at the previously reviewed monorepo commit =e27649a6898b8c5b5bdbb4c6c64fd792672ae0ae=. Both built-in value orderings (=label= and =fiber=) receive independent 250000-state/6-second budgets for each of the 511 exact class representatives.

* Independent certificate replay

Every =FOUND= status must store the complete induced target antipodal pairs and *every* coordinate of the original third-iterate ordinary retraction. A separate independent verifier reconstructs each such \(P_3\) from the *original ten-vertex graph6* using the historical independent NetworkX/bitset Bron--Kerbosch maximal-clique and dominated-vertex paring machinery. It checks the P3 graph6 SHA-256, the target consists of exactly \(d\) pairwise disjoint nonedges with all cross-edges, the projection fixes all \(2d\) target vertices pointwise, and for every source edge \(uv\):

\[
r(u)=r(v)\quad\text{or}\quad r(u)r(v)\in E(O_d).
\]

Thus every accepted full map is an ordinary graph retraction certificate, not merely a matching or homology signature. There are eight disjoint shards covering exactly 511 representatives and 606 original members, each with both native value orderings. The aggregate verifies all 1022 statuses, all positive projections, immutable source provenance and full member propagation; full searchable JSON and aggregate results are published as workflow artifacts.

A negative search result is *not* evidence of clique convergence: =EXHAUSTED= excludes only the searched coaffine-target octahedral retractions, while =LIMIT_REACHED= is resource-inconclusive. Neither status is used to change a census verdict.
