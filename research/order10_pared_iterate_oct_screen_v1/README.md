# Bounded discovery: pared clique iterates of unclassified McKay-ten stiff cores

This exploratory search does not change the certified census. It authenticates the frozen v10 Git blob `35acbd4efbe6fd6816ff0b5c749b8b20b4455d1e`, selects exactly 1,043 original ten-vertex McKay indices with pared order ten and `- - -` status, and records full dominated-vertex folds at every level. Primary graph identifiers are McKay indices, not graph6 strings.

The routine reconstructs pared clique iterates 2, 3 and, when facet limits allow, 4, seeking full ordinary retractions onto `O_d` for `3 <= d <= 8`. It replays every positive map edge-by-edge against the induced target. Exhausted, skipped and bounded cases remain **unclassified**, not proved nondivergent. No homology or Betti calculations.

Eight frozen-index batches run as a GitHub workflow and upload all complete positive witnesses and explicit counts. A separate independent replay/archival PR is required before removing anything from the authoritative index. Existing proof archives and historical stage files remain unchanged.
